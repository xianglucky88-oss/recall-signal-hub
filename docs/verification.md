# 基线验证记录

验证日期：2026-11-12。

## 功能测试

Python 3.11.2（基线另在 Python 3.14.7 验证）、pytest 8.4.2；70 项测试全部通过。

覆盖范围包括两种发布格式、真实本地 HTTP 采集与 webhook、Unicode 标准化、跨来源归并、风险规则、坏记录隔离、事务回滚、游标竞争、持久化退避、并发领取、租约失效隔离、接收端幂等、按目标路由展开与独立记账、订阅漂移显式处理和 CLI。

路由场景（`tests/test_routing.py`）安排两个接收方同时命中同一条告警：一个首次投递失败、另一个成功，验证失败目标独立退避且不影响成功目标；随后修改订阅配置（端点改变、接收方移除、新接收方加入），确认已排队任务仍持有冻结的接收方、端点与配置版本；再令旧领取者在租约过期后迟到确认，确认其抛出 `LeaseLost` 且不能夺走后来领取者的任务。全部接收方均为 `RecordingTargetSink` 或本地 HTTP 替身。

可在安装测试依赖后运行：

```bash
python -m pytest -q
```

## 安装验证

从独立源码副本构建 `recall_signal_hub-0.1.0-py3-none-any.whl`，在新的隔离环境安装，然后在源码目录之外调用安装生成的 `recall-signal-hub` 命令。

验证结果：fixture 采集、案例查询、2 条告警派送、再次派送返回 0 条均通过。验证过程使用本地 wheel，没有连接真实发布方或通知真实接收人。
